# Paws & Claws Shopify Theme

A custom Shopify eCommerce theme for **Paws & Claws**, a modern pet supply store focused primarily on dogs and cats.

The theme is designed to feel warm, trustworthy, polished, family-friendly, and premium while providing a functional Shopify shopping experience.

## Store Categories

- Dogs
- Cats
- Toys
- Beds & Furniture
- Feeding
- Grooming
- Collars & Leashes
- Travel
- Clothing & Accessories
- New Arrivals
- Best Sellers

## Core Features

### Premium Header & Navigation

- Sticky responsive header
- Desktop mega-menu support
- Multi-level navigation
- Mobile navigation drawer
- Predictive search support
- Customer account access
- Cart drawer and live cart count
- Promotional menu areas that only render when configured

### Homepage

The homepage is built from modular Shopify sections and includes:

- Large hero
- Shop Dogs / Shop Cats
- Shop by Category
- Featured Products
- Moving Product Showcase
- Dog editorial feature
- Cat editorial feature
- Trust / Why Paws & Claws section
- Newsletter signup
- Large premium footer

Sections can be reordered, removed, or customized in the Shopify Theme Editor.

### Product Experience

- Product image gallery
- Product title and pricing
- Compare-at pricing
- Variant selectors
- Quantity controls
- Add to Cart
- Buy Now / accelerated checkout support
- Product information accordions
- Shipping and returns information
- Related product recommendations

### Collections

- Responsive product grids
- Shopify-native filtering
- Availability filtering
- Price filtering
- Sorting
- Active filter controls
- Mobile filter drawer
- Pagination

### Cart & Search

- Cart page
- AJAX cart drawer support
- Quantity and remove controls
- Subtotal and checkout
- Free-shipping progress support
- Store search
- Predictive search support
- Search results page

### Pages

Custom layouts are included for:

- About Us
- Contact Us
- FAQ

The Contact page uses Shopify's native contact form system. The FAQ supports expandable accordion items.

## Integration Note

This package is designed to layer onto the Shopify foundation created for Paws & Claws. Review `DELETE-FROM-COPILOT-BASE.txt` and `docs/COPILOT-INTEGRATION.md` before final integration so older template files do not conflict with the modular JSON-template structure.

## Before Publishing

Verify the following in Shopify:

- Navigation menus and collection links
- Collection assignments
- Product inventory and variants
- Shipping settings
- Payment settings
- Store policies
- Contact information
- Social links
- Domain configuration
- Mobile layout
- Search and cart behavior
- Checkout flow

Run Shopify Theme Check in the actual theme environment before publishing.
